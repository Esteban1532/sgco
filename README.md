# SGCO - Sistema de Gestión del Consultorio Odontológico

Proyecto de Ingeniería de Software (Universidad Cooperativa de Colombia).
Autor: Esteban Reinoso.

## Contenido

- `sgco/`: prototipo en Django. Instalación, usuarios de prueba y comandos en [sgco/README.md](sgco/README.md).
- `SGCO - Documento final consolidado.docx`: documento de las fases 1, 2 y 3 (versión 3.0).
- `SGCO - Sustentacion final.pptx`: presentación de la Fase 3.
- `Sustentacion Fase 2 - Consultorio Odontologico.pptx` y `Sustentacion Fase 1 y Fase 2 - Consultorio Odontologico.pptx`: presentaciones de fases anteriores.
- `fuentes/diagramas/`: diagramas UML en Mermaid (.mmd).
- `imagenes/`: diagramas exportados a PNG.
- `fuentes/`: scripts que generan el documento, las presentaciones y las capturas.
